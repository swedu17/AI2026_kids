Optimization Engine

수학적 최적화 알고리즘 (MCLP)

SafeZone Optimizer는 제한된 지자체 예산($B$) 한도 내에서 전체 위험 수요 지점의 총 스코어 가중합을 최대화하는 **최대 커버리지 위치 문제(Max Coverage Location Problem, MCLP)** 수리 모델을 사용합니다.

[목적 함수 - Objective Function]
$$\max \sum_{i \in I} w_i \cdot y_i - \sum_{j \in J} c_j \cdot x_j$$
[주요 제약 조건 - Constraints]

1. 예산 제약: $\sum_{j \in J} c_j \cdot x_j \le B$

2. 커버리지 조건: $y_i \le \sum_{j \in N_i} x_j \quad \forall i \in I$

$w_i$: demand point $i$의 종합 위험 스코어
$x_j \in \{0,1\}$: 후보지 $j$ 설치 여부 결정변수

우선순위 Score 산정 공식

각 수요 지점의 종합 설치 필요성 스코어($Score_i$)는 4가지 핵심 공간 변수의 정규화 가중합으로 실시간 산출됩니다.

$$Score_i = \alpha \overline{R_{width}} + \beta \overline{C_{crime}} + \gamma \overline{A_{blind}} + \delta \overline{P}_{pop}$$
$\alpha$ (0.3) 도로폭 정규화값 ($\overline{R_{width}}$) 도로 폭 및 취약도
$\beta$ (0.3) 범죄/치안 위험도 ($\overline{C_{crime}}$) 5대 범죄 및 여성안심길
$\gamma$ (0.25) 사각지대 면적 ($\overline{A_{blind}}$) 주변 미커버 비율
$\delta$ (0.15) 인구 밀도 ($\overline{P}_{pop}$ ) 유동/유아 인구 수

기술 스택 & 시스템 구조

서버 및 DB 구축 없이 순수 웹 브라우저 단에서 고성능 GIS 연산 수행

구분 기술 스택 선정 사유
Core Engine Vanilla JS (ES2022+) 프레임워크 의존성 없는 가벼운 실행 환경 및 빠르고 독립적인 연산
GIS Rendering Leaflet.js + Leaflet.heat 42KB 경량 지도 라이브러리, 풍부한 공간 마커 및 히트맵 렌더링 지원
Spatial Analysis Turf.js + Proj4.js 브라우저 내 GeoJSON 버퍼 연산, 시선 분석 및 WGS84 ↔ UTM-K 좌표계 변환
File Parser shpjs + FileReader API 지자체 Shapefile(.zip) 및 CSV 데이터를 브라우저 단에서 즉시 GeoJSON으로 변환
Export Engine jsPDF + SheetJS (xlsx) 서버 통신 없이 즉시 다운로드 가능한 PDF 심의 보고서 및 Excel 생성
